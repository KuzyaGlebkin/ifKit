## REMOVED Requirements

### Requirement: Системные ключи для тихой музыки со скринридерами

**Reason:** Переключатель `quietMusicForScreenReader` удалён из продукта.

**Migration:** Заменить использование удалённых ключей на ключи для секции общей громкости (см. ADDED ниже).

## ADDED Requirements

### Requirement: Системные ключи для общей громкости в модалке настроек

Движок SHALL определять стабильные ключи системного UI в пространстве `u()` для **подписи** секции общей громкости и для **пояснения чекбокса** включения общего звука (аналогично ключам для музыки и звуков). Для каждого ключа SHALL быть **непустой** fallback для **языка оригинала** во встроенном `BUILTIN_UI` и, для остальных языков, через `locales[code].ui`, согласованный с `u(key)` и `settings-modal`.

#### Scenario: Ключ подписи секции общей громкости разрешён через u

- **WHEN** вызывается `u` для ключа подписи секции общей громкости
- **THEN** возвращается непустая строка (из локали автора или fallback по правилам движка)

#### Scenario: Ключ чекбокса общего включения звука разрешён через u

- **WHEN** вызывается `u` для ключа пояснения чекбокса общей громкости
- **THEN** возвращается непустая строка (из локали автора или fallback по правилам движка)

## MODIFIED Requirements

### Requirement: Системные ключи для объявляемой громкости ползунков
Движок SHALL определять стабильные ключи `UI` для строки, **озвучиваемой** вспомогательными технологиями для текущего уровня громкости (**общая громкость**, музыка и звуки) и, при едином шаблоне, для **той же** подписи рядом с ползунком, с **плейсхолдером** для целого числа 0–100, чтобы автор локали мог задать порядок «число + проценты» в соответствии с языком. Для ключа SHALL быть **непустой** fallback для **языка оригинала** в `BUILTIN_UI` и, для остальных языков, через `locales[code].ui`, согласованный с `u(key)`.

#### Scenario: Ключ уровня громкости разрешён

- **WHEN** шаблон с `{0}` подставляется в строку из `u` по ключу уровня громкости
- **THEN** возвращается непустая локализованная строка, содержащая **целое** процентное значение, а не сырую десятичную долю 0.0–1.0
