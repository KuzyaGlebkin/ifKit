## Why

Переключатель «Тихая музыка для скринридера» усложняет настройки и решает узкую задачу; вместо него нужна понятная общая регулировка громкости. Отдельная настройка «Громкость» между «Акцент» и «Музыка» даёт игроку один масштаб для всего звука при том же привычном интерфейсе, что у строк «Музыка» и «Звуки».

## What Changes

- Удалить из модалки настроек элемент «Тихая музыка» (`quietMusicForScreenReader`) и связанные требования к UI и i18n для этого переключателя.
- Удалить поле `quietMusicForScreenReader` из схемы `Settings`, загрузки/сохранения и аудиопайплайна; при чтении старых сохранений игнорировать или отбрасывать устаревший ключ без ошибок (**BREAKING** для сохранённого JSON и публичного типа настроек).
- Добавить поля общей громкости в духе строк «Музыка»/«Звуки»: номинальный уровень (0–1), шаг и отображение в процентах, отдельный флаг «ветка включена» (аналог mute), немедленное применение к аудиодвижку и сохранение в `ifkit:settings`.
- Разместить секцию «Громкость» в модалке **между** блоком «Акцент» и блоком «Музыка»; порядок Tab и доступность ползунка — по тем же правилам, что у ползунков музыки и звуков.
- Эффективная слышимость музыки и звуков SHALL масштабироваться общим множителем (и общим отключением), поверх существующих `musicVolume` / `soundVolume` и их mute.

## Capabilities

### New Capabilities

— (нет новых capability-файлов; изменения — дельты к существующим спекам.)

### Modified Capabilities

- `user-settings`: заменить `quietMusicForScreenReader` на поля общей громкости; обновить требования про связь настроек с аудиодвижком и миграцию/совместимость хранилища.
- `settings-modal`: убрать переключатель тихой музыки; добавить строку «Громкость» между «Акцент» и «Музыка» с тем же паттерном UI, что у музыки/звуков; обновить сценарии сброса/импорта и Tab.
- `audio-engine`: убрать множитель α и API `setQuietMusicForScreenReader`; ввести общий мастер-множитель (и mute) в формулах эффективного gain для музыки и звуков.
- `i18n`: заменить ключи UI для тихой музыки на строки для секции «Громкость» (и при необходимости вспомогательный текст для AT), согласованные с модалкой.

## Impact

- `src/ifKit/settings.ts`, `settings-modal.ts`, `audio.ts`, `engine.ts`, встроенный UI (`builtin-ui` / разметка модалки), локали `*.ui.json`.
- Экспорт/импорт настроек и существующие сохранения игроков: поле `quietMusicForScreenReader` перестаёт быть частью контракта; старые файлы с этим ключом обрабатываются без падения.
- Спеки: дельты под `openspec/changes/master-volume-setting/specs/{user-settings,settings-modal,audio-engine,i18n}/spec.md`.
