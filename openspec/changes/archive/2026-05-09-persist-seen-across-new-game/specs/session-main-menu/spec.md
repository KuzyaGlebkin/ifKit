## MODIFIED Requirements

### Requirement: Кнопка «Новая игра» с иконкой Plus

Кнопка начала новой игры SHALL отображать иконку **Plus** из набора Lucide (или эквивалентная векторная иконка из того же источника, что использует движок для Lucide). По активации движок SHALL начинать игру с первой сцены согласно конфигурации `defineGame` (как при обычном старте без сохранённого состояния из меню), переводить сессию в режим «игра» и скрывать стартовое меню. Движок SHALL NOT сбрасывать учёт просмотренного контента (`ifkit:seen`, см. `seen-content`) в рамках этого действия.

#### Scenario: Новая игра запускает цикл

- **WHEN** пользователь активирует «Новая игра» из стартового меню
- **THEN** отображается обычный интерфейс с `#controls` и первой сценой; стартовое меню скрыто

#### Scenario: Новая игра сохраняет просмотренный контент в localStorage

- **WHEN** пользователь ранее просматривал игровой текст в этой сессии браузера, из‑за чего в `ifkit:seen` записаны хеши блоков, и затем активирует «Новая игра» из стартового меню
- **THEN** после запуска цикл отображается как в сценарии выше, а `ifkit:seen` не удаляется и не заменяется пустым объектом только из‑за этого действия
