## ADDED Requirements

### Requirement: Сброс просмотренного контента только по явному действию в настройках

Движок SHALL NOT вызывать `resetSeenContent()` при старте новой игры из стартового меню сессии (кнопка «Новая игра» / эквивалент). Полный сброс хранилища `ifkit:seen` SHALL выполняться только по пользовательскому действию в модалке настроек, которое специфицировано в `settings-modal` (кнопка сброса истории прочтения, вызывающая `resetSeenContent()`).

#### Scenario: Новая игра не очищает ifkit:seen

- **WHEN** в `localStorage` есть ключ `ifkit:seen` с непустыми данными и пользователь активирует «Новая игра» в стартовом меню
- **THEN** после запуска первой сцены ключ `ifkit:seen` по-прежнему существует и его содержимое для целей учёта seen не очищено этим действием

#### Scenario: Сброс через настройки по-прежнему очищает seen

- **WHEN** пользователь нажимает кнопку сброса истории прочтения в модалке настроек
- **THEN** вызывается `resetSeenContent()` и хранилище seen очищается согласно существующему требованию «resetSeenContent очищает хранилище»
