## Context

Учёт «просмотренных» блоков (`seen-content`) хранится в `localStorage` под ключом `ifkit:seen`. В `session-main-menu` обработчик «Новая игра» сегодня вызывает `resetSeenContent()` перед сбросом состояния игры, из‑за чего при каждом новом прохождении теряется история просмотра. Отдельно в модалке настроек уже есть кнопка «Сбросить историю прочтения», вызывающая `resetSeenContent()` (см. `settings-modal`).

## Goals / Non-Goals

**Goals:**

- Не очищать `ifkit:seen` при выборе «Новая игра» в стартовом меню.
- Сохранить единственный явный сброс через настройки без изменения контракта `resetSeenContent()`.

**Non-Goals:**

- Привязка seen к слотам сохранений или к отдельным «прохождениям».
- Изменение формата `ifkit:seen` или логики `markAndHighlight`.
- Новая кнопка сброса (уже есть в настройках).

## Decisions

1. **Удалить вызов `resetSeenContent()` из обработчика «Новая игра».**  
   **Rationale:** Минимальное изменение; хранилище остаётся общим для вкладки, как и задумано для seen.  
   **Alternatives:** Вызывать `resetSeenContent` только при первом визите — отклонено: лишняя эвристика и расхождение с запросом пользователя.

2. **Не трогать `resetGameToInitial` и загрузку слотов.**  
   **Rationale:** Запрос касается только сценария «Новая игра» из меню; загрузка сохранения не должна подразумевать сброс seen (и сейчас не сбрасывает).

3. **Спецификации:** дельта `session-main-menu` (кнопка Plus) и дельта `seen-content` (где допустим вызов `resetSeenContent`).  
   **Rationale:** Явный контракт на будущее, чтобы снова не привязать сброс к новой игре.

## Risks / Trade-offs

- **[Risk]** Автор/игрок ожидал «чистого» seen при каждой новой игре.  
  **Mitigation:** Явный сброс в настройках; спека фиксирует выбранное поведение.

- **[Trade-off]** Seen остаётся глобальным на игру в браузере — при полном переписывании текста игры старые хеши могут быть малополезны, но не ломают подсветку (новый HTML → новые хеши).

## Migration Plan

- Деплой: обычный релиз; откат — вернуть одну строку вызова в `session-main-menu` при необходимости.
- Данные игроков: без миграции; существующие ключи `ifkit:seen` сохраняются.
