## Why

Сейчас при выборе «Новая игра» движок сбрасывает учёт просмотренных блоков (`ifkit:seen`), из‑за чего игрок снова видит подсветку «нового» текста, хотя он уже читал его в прошлых прохождениях. Ожидаемое поведение — сохранять просмотренный контент между запусками новой игры в рамках одной вкладки/браузера; сброс только по явному действию игрока («Сбросить историю» в настройках).

## What Changes

- Убрать автоматический вызов сброса просмотренного контента при старте новой игры из сессионного главного меню (сейчас это делается перед `resetGameToInitial`).
- Оставить единственный пользовательский путь полного сброса учёта seen — существующее действие в настройках («Сбросить историю» / эквивалент), которое по-прежнему вызывает `resetSeenContent()`.
- Поведение загрузки сохранения и остальной игровой логики не меняется намеренно: ключ `ifkit:seen` остаётся глобальным для игры в хранилище.

### Modified Capabilities

- `seen-content`: зафиксировать, что `resetSeenContent()` не вызывается автоматически при «Новая игра»; сброс только по явному UI в настройках.
- `session-main-menu`: сценарий «Новая игра» не SHALL сбрасывать хранилище `ifkit:seen`.

## Impact

- `src/ifKit/session-main-menu.ts` — удалить или не вызывать `resetSeenContent` в обработчике «Новая игра».
- `src/ifKit/settings-modal.ts` — без функциональных изменений, если кнопка сброса уже вызывает `resetSeenContent` (проверить при внедрении).
- Спецификации OpenSpec: дельты к `seen-content`, `session-main-menu`.
