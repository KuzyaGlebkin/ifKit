## ADDED Requirements

### Requirement: Регионы seen при наличии static в defineGame
Когда в `defineGame` передано поле `static`, движок SHALL собирать HTML для `#scene-content` из трёх частей в порядке: зона `before`, затем тело сцены (с подстановкой `Slot`), затем зона `after`. Каждая непустая часть SHALL оборачиваться в контейнер, различимый движком для раздельного учёта «просмотренного» текста: контейнеры before и after SHALL помечаться как область глобального seen для static; контейнер тела сцены SHALL помечаться как область per-scene seen. Пустые before или after не обязаны порождать контейнер. Визуальный порядок фрагментов для пользователя SHALL совпадать с текущим поведением конкатенации `before + scene + after`.

#### Scenario: Только before и тело — порядок как раньше
- **WHEN** static задаёт `before` с контентом, `after` пуст, сцена выводит абзац
- **THEN** в `#scene-content` сначала идут блоки before (в своём контейнере региона static), затем блоки сцены (в контейнере региона scene), без лишнего контейнера для пустого after

#### Scenario: Игра без static — плоская структура сохраняется
- **WHEN** поле `static` в `defineGame` отсутствует
- **THEN** в `#scene-content` нет контейнеров регионов seen; разметка соответствует только HTML сцены, как до этого изменения
