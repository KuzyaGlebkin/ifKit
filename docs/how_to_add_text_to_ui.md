# Как добавить текст в интерфейс (UI) с текущей интернационализацией

В ifKit интернационализация (i18n) разделена на два слоя:

- **Игровой текст** – переводятся через tagged template literal `t``…``.
- **UI‑текст** (панели, модалки, кнопки и т.п.) – переводятся через функцию `u(key)`.

Эта инструкция описывает, как добавить новый элемент UI‑текста и обеспечить его поддержку нескольких языков.

---

## 1. Определите, нужен ли новый ключ

Откройте файл `src/ifKit/ui-keys.ts`. В нём объявлен объект `UI` со всеми стабильными ключами, используемыми в интерфейсе.

Если нужный вам элемент уже присутствует (например, `ui.settingsTitle`), переходите к шагу 2.  
Если ключа нет – добавьте его.

**Пример добавления нового ключа**

```ts
export const UI = {
  // … существующие ключи
  // Новый ключ для подписи кнопки «Подтвердить»
  settingsConfirm: 'ui.settingsConfirm',
} as const
```

После добавления нового ключа обновите тип `UiKey` (он обновляется автоматически, так как выведен из `UI`).

---

## 2. Добавьте переводы в языковые файлы

Переводы UI хранятся в папке `src/locales/` в файлах вида `<lang>.ui.json` (или `<lang>.ui.ts` для TypeScript).  
Для каждого поддерживаемого языка добавьте запись с тем же ключом, что вы определили в `ui-keys.ts`.

**Пример для английского (`en.ui.json`)**

```json
{
  // … существующие записи
  "ui.settingsConfirm": "Confirm"
}
```

**Пример для русского (`ru.ui.json`)**

```json
{
  // … существующие записи
  "ui.settingsConfirm": "Подтвердить"
}
```

Если вы используете TypeScript‑файлы (`.ui.ts`), структура такая же – экспортируйте объект с записями.

> **Важно:** оставляйте пустым значение только если хотите, чтобы использовался fallback (см. шаг 3). В качестве fallback движок сначала ищет в Built‑in UI для исходного языка, затем в других объявленных локалях.

---

## 3. Проверьте наличие fallback в Built‑in UI

Файл `src/ifKit/builtin-ui.ts` содержит готовые строки для исходного языка (по‑умолчанию – русский).  
Если ваш язык – исходный (ru), добавьте строку туда, чтобы гарантировать наличие fallback даже если автор не переведёт её в своих локалях.

**Пример добавления в `builtin-ui.ts` (для русского)**

```ts
ru: {
  // …
  [UI.settingsConfirm]: 'Подтвердить',
  // …
},
```

Для других языков fallback будет браться из Built‑in UI исходного языка или из другой объявленной локали (например, `en`).

---

## 4. Используйте перевод в коде

Где‑бы вы ни хотели отобразить UI‑строку, импортируйте функцию `u` и передайте ей ключ.

```ts
import { u } from './ifKit';
import { UI } from './ifKit/ui-keys';

// где‑то в рендер‑функции
const confirmButtonLabel = u(UI.settingsConfirm);
// или напрямую строку:
const confirmButtonLabel = u('ui.settingsConfirm');
```

Функция `u` выполнит поиск в текущей resolved локали, применит fallback‑правила и вернёт готовую строку.

---

## 5. (Опционально) Обновите шаблоны извлечения

Если вы добавляете новый ключ через `t``…`` (игровой текст), запустите скрипт извлечения, чтобы обновить шаблоны переводов.  
Для UI‑текста скрипт извлечения **не** требуется, так как ключи явно объявлены в `ui-keys.ts` и переводы хранятся вручную в `.ui.json/.ui.ts`.

Однако, если вы изменили существующий ключ UI, убедитесь, что все языковые файлы содержат актуальное значение.

---

## 6. Проверьте работу

1. Запустите проект: `npm run dev`.
2. Откройте настройки или место, где используется ваш новый элемент.
3. Переключите язык в настройках (или через `setLanguage` в консоли) и убедитесь, что текст меняется соответствующим образом.
4. При выборе «Авто» (пустой язык) убедитесь, что используется язык, определённый из `navigator.language` или первый доступный.

---

## 7. Пример полного цикла

Добавим подпись для переключателя «Показывать подсветку» в модалке настроек.

1. **ui-keys.ts**

   ```ts
   export const UI = {
     // …
     settingsHighlightToggle: 'ui.settingsHighlightToggle',
   } as const
   ```

2. **en.ui.json**

   ```json
   { "ui.settingsHighlightToggle": "Highlight text" }
   ```

3. **ru.ui.json**

   ```json
   { "ui.settingsHighlightToggle": "Подсветка текста" }
   ```

4. **builtin-ui.ts** (для русского fallback)

   ```ts
   ru: {
     // …
     [UI.settingsHighlightToggle]: 'Подсветка текста',
   }
   ```

5. **Использование в коде** (например, в `settings-modal.ts`)

   ```ts
   import { u } from './ifKit';
   import { UI } from './ifKit/ui-keys';

   // внутри рендер‑функции модалки
   const label = u(UI.settingsHighlightToggle);
   ```

Готово! Теперь новая строка локализуется вместе с остальным интерфейсом.

---

## Связанные файлы

- `src/ifKit/ui-keys.ts` – объявление стабильных ключей UI.
- `src/ifKit/builtin-ui.ts` – fallback‑строки для исходного языка.
- `src/ifKit/i18n.ts` – реализация функций `u`, `t`, `initI18n` и т.д.
- `src/locales/<lang>.ui.json` (или `.ui.ts`) – переводы UI для каждого языка.
- `src/ifKit/settings-modal.ts` (и другие файлы UI) – примеры использования `u()`.

---

> **Примечание:** Если вы добавляете текст, который относится к игровой сцене (диалоги, описания, подписи кнопок действий), используйте tagged template literal `t``…`` и файлы `*.game.json`. Инструкция по добавлению игрового текста аналогична, но работает с функцией `t` и слоем `game` локалей.
